示例与边界：登录表单、登录规则和登录接口调用

本层结构：
data/（登录注册数据层）：放本功能的数据仓库及数据转换。仓库协调网络与本地来源，界面不直接操作底层网络客户端或数据库。
domain/（登录注册业务规则层）：放需要复用或比较复杂的业务规则、业务模型和用例；简单功能可以直接由 ui 调用数据仓库，不必强行使用这一层。
ui/（登录注册界面层）：放 Activity、Fragment、ViewModel、界面状态与界面事件；页面负责展示并响应操作。
