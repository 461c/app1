首页
路径：app/src/main/java/com/example/learningapp/feature/home

职责：已有点击计数器，后续可扩展首页列表或推荐内容。
当前状态：已有计数器页面；domain/data 尚未实现。

示例与边界：首页数据、展示状态和业务规则

本层结构：
data/（首页数据层）：放本功能的数据仓库及数据转换。仓库协调网络与本地来源，界面不直接操作底层网络客户端或数据库。
domain/（首页业务规则层）：放需要复用或比较复杂的业务规则、业务模型和用例；简单功能可以直接由 ui 调用数据仓库，不必强行使用这一层。
ui/（首页界面层）：放 Activity、Fragment、ViewModel、界面状态与界面事件；页面负责展示并响应操作。
文件夹说明.txt：本目录说明。
