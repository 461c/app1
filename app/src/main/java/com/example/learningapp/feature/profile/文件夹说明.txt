个人中心
路径：app/src/main/java/com/example/learningapp/feature/profile

职责：后续放用户资料展示与资料编辑。
当前状态：结构预留：尚未实现 个人中心 功能。

示例与边界：资料页面、资料校验和资料读写

本层结构：
data/（个人中心数据层）：放本功能的数据仓库及数据转换。仓库协调网络与本地来源，界面不直接操作底层网络客户端或数据库。
domain/（个人中心业务规则层）：放需要复用或比较复杂的业务规则、业务模型和用例；简单功能可以直接由 ui 调用数据仓库，不必强行使用这一层。
ui/（个人中心界面层）：放 Activity、Fragment、ViewModel、界面状态与界面事件；页面负责展示并响应操作。
