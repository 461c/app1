公共基础能力
路径：app/src/main/java/com/example/learningapp/core

职责：放确实被多个业务功能使用的能力。某个功能专用的代码继续放在该功能中，避免 core 变成杂物堆。
当前状态：结构预留：当前只有说明文档，相关功能尚未实现。

示例与边界：network、database、preferences、model、ui、util 都是预留包。

本层结构：
database/（数据库基础设施）：统一管理数据库连接、表的访问与版本迁移。
model/（共享数据类型）：放多个业务功能确实共用的数据类型；仅在一个功能使用的模型应留在该功能内。
network/（网络基础设施）：统一管理网络客户端、请求配置、超时和通用错误处理。
preferences/（轻量偏好存储）：保存主题、语言、开关等少量设置，和关系型数据库区分。
ui/（公共界面组件）：放跨功能复用的按钮、加载提示、错误提示或基础界面组件。
util/（通用小工具）：放职责清晰的日期格式化、字符串处理等小工具。
文件夹说明.txt：本目录说明。
