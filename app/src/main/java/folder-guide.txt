Kotlin / Java 源代码根目录
路径：app/src/main/java

目录名为 java 也可以存放 .kt 文件。下级路径 com/example/learningapp 对应包名 com.example.learningapp。

本层结构：
com/：com 是当前示例包名的第一段；它只是代码命名层级，不是独立功能模块。
folder-guide.txt：本文件，说明当前文件夹及直接子项。
code-guide.txt（存在时）：同目录源码的逐行解释，对应修改后的实际行号。

阅读方法：先读 folder-guide.txt，再读源码中的中文注释，必要时按行号查看 code-guide.txt。
空白行用于分段，没有执行效果。注释不会作为业务逻辑执行。
