# 从计数器到大应用

已完成：Kotlin 点击计数器、XML 页面、临时状态恢复、逐行中文注释、按功能分包的目录骨架。

建议按以下顺序继续，每一步完成后再开始下一步：

1. 阅读 `feature/home/ui/MainActivity.kt` 与 `res/layout/activity_main.xml`，理解事件如何更新页面。
2. 把计数规则从 Activity 抽成独立 Kotlin 类，再添加本地测试；届时补充 JUnit 依赖。
3. 实现设置页面，在本地保存一个真实的偏好开关，理解 ui 与 data 的边界。
4. 实现个人中心的静态页面，再学习页面跳转。
5. 用明确标注的假数据练习仓库接口，再接真实网络；不要把演示数据当作真实登录系统。
6. 学习数据库、异步请求、错误处理和界面状态管理。
7. 配置设备测试和构建检查；有实际团队或构建需求后，再拆分 Gradle 模块。

阅读时每次只进入一个功能目录，不需要一次记住全部路径。目录层级是为了帮助定位，不是应用功能必须复杂的要求。
